<Steps>

1. Back up the forum's database and files.

2. Download [the latest release](https://github.com/southern-cross-garrison/mybb-plugin-events/releases/latest/download/mybb-plugin-events.zip)
   and check its
   [release notes](https://github.com/southern-cross-garrison/mybb-plugin-events/releases)
   for anything to do before upgrading.

3. Upload the new files over the old ones, the same way as
   [installing](../installing/#upload-the-files).

4. Go to **Admin CP** > **Configuration** > **Plugins**.

5. Click **Deactivate** beside **Event Management**, then **Activate**.

   <Image src={deactivate} alt="Deactivate circled beside Event Management" />

</Steps>

Reactivating is the upgrade step. It:

- applies any database changes the new version needs
- adds new settings, leaving existing ones as they are
- updates the plugin's templates and stylesheet

<Aside type="danger" title="Deactivate, don't uninstall">
  **Uninstall** deletes every event, signup and troop record. See
  [Uninstalling](../uninstalling/).
</Aside>

<Aside type="caution" title="Template edits">
  Reactivating replaces the plugin's templates and stylesheet with the new version's. Put
  theme changes in your theme's own stylesheet instead. See [Theming](../theming/).
</Aside>
