The plugin keeps members' details in MyBB custom profile fields, so members can also edit
them in [**User CP** > **Edit Profile**](https://501scg.org/forum/usercp.php?action=profile). Create them before configuring the plugin.

| Field                 | Type     | Viewable By | Notes                                                                                                                                                  |
| --------------------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Costumes**          | Textarea | All groups  | One costume per line. Overwritten from the 501st Legion each time a member signs up to troop. A multi-select or comma-separated text field also works. |
| **Legion ID**         | Text     | All groups  | For example if you are `TK-12345`, enter `12345`.                                                                                                      |
| **WWCC**              | Text     | None        | Not needed if checks are turned off.                                                                                                                   |
| **Mobile Number**     | Text     | None        |                                                                                                                                                        |
| **Emergency Contact** | Text     | None        |                                                                                                                                                        |
| **Preferred Name**    | Text     | All groups  | Shown on the attendance sheet.                                                                                                                         |

## Create a field

<Steps>

1. Go to **Admin CP** > **Configuration** > **Custom Profile Fields** and click **Add New
   Profile Field**.

2. Fill in the **Title** and **Field Type** from the table above.

3. Set **Editable By** to **All groups**, so members can update it.

4. Set **Viewable By** from the table above. The plugin shows **None** fields on attendance
   sheets regardless, and staff with Admin CP or Mod CP access still see them on profiles.

   <Image src={visibility} alt="Viewable By and Editable By circled on the profile field form" />

5. Save the field.

</Steps>

Then pick each field on **Event Management** > **Settings**. See [Settings](../settings/).

<Image src={pickCostumes} alt="The costume and Legion ID profile field settings circled" />

<Image src={pickContact} alt="The check, mobile, emergency contact and preferred name profile field settings circled" />

<Aside type="caution">
  Set **Viewable By** to **None** on WWCC, Mobile Number and Emergency Contact. With
  **All groups**, every member can see them on profiles.
</Aside>
