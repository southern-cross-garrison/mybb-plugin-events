The plugin keeps members' details in MyBB custom profile fields, so members can also edit
them in **User CP** > **Edit Profile**. Create them before configuring the plugin.

| Field                 | Type     | Viewable by             | Notes                                                                                                                                                  |
| --------------------- | -------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Costumes**          | Textarea | Everyone                | One costume per line. Overwritten from the 501st Legion each time a member signs up to troop. A multi-select or comma-separated text field also works. |
| **Legion ID**         | Text     | Everyone                | For example if you are `TK-12345`, enter `12345`.                                                                                                      |
| **WWCC**              | Text     | Admins and coordinators | Not needed if checks are turned off.                                                                                                                   |
| **Mobile Number**     | Text     | Admins and coordinators |                                                                                                                                                        |
| **Emergency Contact** | Text     | Admins and coordinators |                                                                                                                                                        |
| **Preferred Name**    | Text     | Everyone                | Shown on the attendance sheet.                                                                                                                         |

## Create a field

<Steps>

1. Go to **Admin CP** > **Configuration** > **Custom Profile Fields** and click **Add New
   Profile Field**.

2. Fill in the **Title** and **Field Type** from the table above.

3. Set **Editable By** to all registered groups, so members can update it.

4. For the private fields, set **Viewable By** to administrators and your event
   coordinator groups only.

   <Image src={visibility} alt="Viewable By and Editable By circled on the profile field form" />

5. Save the field.

</Steps>

Then pick each field on **Event Management** > **Settings**. See [Settings](../settings/).

<Image src={pickCostumes} alt="The costume and Legion ID profile field settings circled" />

<Image src={pickContact} alt="The check, mobile, emergency contact and preferred name profile field settings circled" />

<Aside type="caution">
  Keep mobile numbers, emergency contacts and WWCC numbers private. The plugin
  only shows them on attendance sheets, but MyBB shows profile fields on
  profiles and posts unless **Viewable By** says otherwise.
</Aside>
