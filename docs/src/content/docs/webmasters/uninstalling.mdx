---
title: Uninstalling
description: Turn the plugin off, or remove it and its data.
sidebar:
  order: 9
---

import { Aside } from '@astrojs/starlight/components';

Go to **Admin CP** > **Configuration** > **Plugins**.

| | Deactivate | Uninstall |
| --- | --- | --- |
| Events, signups, troop history | Kept | **Deleted** |
| Settings | Kept | Deleted |
| Templates and stylesheet | Kept | Deleted |
| Reminder task | Removed | Removed |
| Announcement threads and troop reports | Kept | Kept (they're ordinary forum threads) |

<Aside type="danger">
  Uninstalling can't be undone. Back up the database first.
</Aside>

After uninstalling, delete the plugin's files from the forum root (see
[Installing](../installing/#upload-the-files) for the list). The custom profile fields
are yours and stay.
