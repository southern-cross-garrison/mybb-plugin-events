| | |
| --- | --- |
| **MyBB** | 1.8 (tested on 1.8.41) |
| **PHP** | 7.4 or later (tested on 7.4 and 8.5) |
| **Database** | MySQL or MariaDB, with `utf8mb4` support |
| **PHP curl extension** | Needed to fetch costumes from the 501st Legion. Without it, members' saved costumes are used. |
| **Custom profile fields** | Six, created before configuring the plugin. See [Custom profile fields](../profile-fields/). |

The plugin replaces the forum's **Calendar** menu link with **Events**, so your theme's
header needs a Calendar link.
