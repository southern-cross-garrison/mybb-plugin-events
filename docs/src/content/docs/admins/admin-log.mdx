title: The admin log
description: The record of who created, changed or deleted events.
sidebar:
  order: 7
---

Changes to events are recorded in **Admin CP** > **Tools & Maintenance** >
**Administrator Log**, under the **events** module. This includes changes coordinators
make from the forum.

| Logged | Example |
| --- | --- |
| Creating an event | Created *Supanova Sydney* from the front end |
| Editing an event | Edited *Supanova Sydney* - changed address, start date |
| Changing status | Set *Supanova Sydney* to live |
| Deleting an event | Deleted event #42 (Supanova Sydney) |
| Removing someone's signup | Removed *trooper1* from *Supanova Sydney* - sent a PM |
