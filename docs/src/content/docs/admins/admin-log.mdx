Changes to events are recorded in **Admin CP** > **Tools & Maintenance** >
**Administrator Log**, under the **events** module. This includes changes coordinators
make from the forum.

<Image src={adminLog} alt="The Administrator Log filtered to the events module" />

| Logged                    | Example                                                |
| ------------------------- | ------------------------------------------------------ |
| Creating an event         | Created _Supanova Sydney_ from the front end           |
| Editing an event          | Edited _Supanova Sydney_ - changed address, start date |
| Changing status           | Set _Supanova Sydney_ to live                          |
| Deleting an event         | Deleted event #42 (Supanova Sydney)                    |
| Removing someone's signup | Removed _trooper1_ from _Supanova Sydney_ - sent a PM  |
