For administrators. You can do everything in the
[coordinators' guide](../coordinators/), plus the **Event Management** section of the
Admin CP. Click **Event Management** in the Admin CP's top menu, then use the tabs:

<Image src={eventManagement} alt="Event Management in the Admin CP's top menu, and its tabs, circled" />

| Tab | For |
| --- | --- |
| **Events** | Every event, including deleting them. |
| **RSVPs** | Who's signed up to an event. |
| **Reports** | Troop counts by member, event, region and costume. |
| **Settings** | Regions, coordinator groups, costumes and checks. |
| **Support** | Credits, licence and where to get help. |
