Coordinators can create, edit and manage any event from the forum, and see attendance
sheets. Administrators always can.

## Make someone a coordinator

Add them to one of the **Event Coordinator User Groups**, as their primary or an
additional group.

To choose which groups count:

<Steps>

1. Go to **Admin CP** > **Event Management** > **Settings**.

2. Select the groups in **Event Coordinator User Groups**. Hold Ctrl (or Cmd on a Mac) to
   select more than one.

   <Image src={coordGroups} alt="Event Coordinator User Groups circled on the Settings page" />

3. Click **Save Settings**.

</Steps>

## Who can run an event

An event's **Coordinator** list is everyone in the coordinator groups, plus whoever is
filling in the form, plus the event's current coordinator.

<Image src={coordDropdown} alt="The Coordinator list on the event form circled" />

If an event's coordinator has been deleted, the list shows **Choose a coordinator** and
the event can't be saved until someone is picked.
