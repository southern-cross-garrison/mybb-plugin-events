All of these are on **Admin CP** > **Event Management** > **Settings**.

## Costumes from the 501st Legion

When a member signs up to troop, their approved costumes are fetched from the 501st Legion
by their Legion ID and saved to their profile. **501st Legion API** is set to
`https://api.501st.com` by default. Clear it to use only the costumes on members'
profiles.

<Image src={legionApi} alt="501st Legion API circled on the Settings page" />

## Preapproved costumes

Let members troop in a costume that's preapproved but not yet on their Legion record.

<Steps>

1. Post the steps members must follow to get preapproval, for example in a rules forum.

2. Tick **Preapproved Costumes**.

3. Paste a link to your post into **Preapproval Requirements**.

   <Image src={preapprovalSettings} alt="Preapproved Costumes and Preapproval Requirements circled" />

4. Click **Save Settings**.

</Steps>

Members using a preapproved costume are shown your post and must confirm they've followed
it, every time.

<Image src={preapprovalMember} alt="The preapproval post shown to a member signing up, circled" />

## Working With Children Checks

Coordinators can require attendees to have a check on file for an event.

<Image src={wwcc} alt="Working With Children Checks and Check Name circled" />

- Untick **Working With Children Checks** if the garrison doesn't use them.
- Set **Check Name** to what your state calls it, for example **Blue Card** in Queensland.
