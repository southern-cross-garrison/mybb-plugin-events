When an event goes **Live**, a thread is posted for it in its region's forum. It's built
from the event: dates, address, coordinator, cutoff, requirements, the day-by-day
schedule and the description. You don't write it.

Members see the event details at the top of the thread, with the discussion as replies
underneath.

## When you edit the event

- The thread's first post is updated to match. No new thread is posted.
- Changing the region moves the thread to that region's forum, unless a moderator has
  already moved it somewhere else.
- If the thread has been deleted, saving the event posts a new one.

## When there's no thread

- Pending events aren't announced.
- If the event's region has no announcement forum, you're told when you save. Ask an
  administrator to set one.
