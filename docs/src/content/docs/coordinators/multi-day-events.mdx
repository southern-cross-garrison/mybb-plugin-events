When the start and end dates are on different days, the form adds an **Event Days** row for
each day. Each row starts with the event's own start and end times - Friday 9:00 to Sunday
18:00 gives three days of 9:00 to 18:00 - so change only the days that differ.

<Image src={days} alt="The Event Days rows on the event form" />

Members can then troop, wrangle or skip each day separately, and
[limits](../managing-signups/#limits-and-the-waitlist) apply to each day.

## Overnight events

An event that runs past midnight isn't a second day. A day whose end time is earlier than
its start time runs overnight, and must finish before the next day's start time.

For example, two nights of 22:00 to 01:00 are two rows, not four.

<Aside>
  Two sessions on the same date, like a morning and an afternoon, are one day. Members
  sign up for the day.
</Aside>

## Removing a day

If you shorten an event and a removed day has signups, the form lists who's affected and
asks you to confirm. Confirming **cancels their whole signup**, not just that day, and sends
them a message asking them to sign up again. See
[Changes that affect signups](../editing-events/#changes-that-affect-signups). If one of
them is the point of contact, see
[Removing the point of contact](../managing-signups/#removing-the-point-of-contact).
