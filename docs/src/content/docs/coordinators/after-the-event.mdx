Once the event ends, it shows **Needs Troop Report** until someone posts one. Anyone who
signed up to troop can write it; see [Writing a troop report](../../members/troop-reports/).

<Image src={needsReport} alt="Needs Troop Report circled in the events list" />

The report decides who's credited with the troop. Make sure it:

- lists everyone who came, including anyone who came off the waitlist on the day
- doesn't list anyone who didn't turn up

Posting the report archives the event.

<Image src={posted} alt="A posted troop report" />

## Reminders

Until the report is posted, troopers get a weekly **Troop Report Needed** message. If it's
still not posted, message the troopers yourself, or write it if you trooped.

<Aside type="tip" title="Fixing a report">
	Edit the report's first post. Who's credited is worked out again from the edited version.
</Aside>
